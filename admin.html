Étape préalable

Connecte ton projet Firebase

Le site fonctionne déjà en mode statique. Pour publier des photos depuis cette page :

  1. Crée un projet sur console.firebase.google.com.
  2. Ajoute une application Web (icône </>) et copie l'objet firebaseConfig.
  3. Colle-le dans js/firebase-config.js.
  4. Active Authentication → Google et crée une base Firestore.
  5. Copie le contenu de firestore.rules dans l'onglet Règles de Firestore et publie.

Le guide complet est dans le fichier README.md du dépôt.
